## Definição e catálogo

- As 12 colunas, defaults e nulabilidade correspondem à seção aprovada: `id`, `account_id`, `created_by`, `provider`, `base_url`, `instance_name`, `token_encrypted`, `webhook_secret_encrypted`, `state`, `state_checked_at`, `created_at`, `updated_at`.
- Constraints observadas: PK `whatsapp_connections_pkey`; FK de `account_id` para `accounts` com cascade; FK de `created_by` para `auth.users` com restrict; unique `account_id`; check `provider='evolution'`; check dos quatro estados aprovados; unique `(base_url, instance_name)`.
- `relrowsecurity=true`, zero policies. ACL direta contém somente owner e `service_role`; nenhuma concessão para `PUBLIC`, `anon` ou `authenticated`. Privilégios efetivos de leitura/escrita para `anon` e `authenticated` são falsos; `service_role` tem SELECT/INSERT/UPDATE/DELETE explícitos.
- Trigger `set_whatsapp_connections_updated_at` executa `public.update_updated_at_column()`, função existente e já usada por triggers análogos do schema.

## Teste transacional real

Comando executado contra o Postgres local, sem credenciais de aplicação:

```sh
docker exec -i supabase_db_wacrm-local psql -U postgres -d postgres -X -v ON_ERROR_STOP=1 -f - < supabase/tests/evolution-connections.sql
```

O arquivo cria dois usuários e contas descartáveis em `auth.users`/`profiles` dentro da transação; usa `service_role` para inserir, ler e atualizar; verifica defaults; espera rejeição de segunda conexão da mesma conta, par repetido `(base_url, instance_name)` entre contas, provider inválido e state inválido; troca para `authenticated` com subject A e B e para `anon`, confirmando negação de SELECT/INSERT e, para authenticated A/B, UPDATE/DELETE. Confere RLS, ausência de policies, ACLs e grants de `service_role`. Os valores ciphertext são marcadores sintéticos, não segredos.

Resultado: todos os blocos `DO` concluíram e o script terminou em `ROLLBACK`. Uma consulta posterior confirmou zero usuários fixture persistidos. O teste foi executado novamente após ampliar as assertions de ACL e de escrita de B; ambas as execuções terminaram em rollback sem alterações duráveis.

## Limites
