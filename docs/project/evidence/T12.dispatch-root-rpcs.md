# T12 — claim de dispatch roots

Data: 2026-11-16. Implementada somente `claim_evolution_dispatches`; `complete_evolution_dispatch` foi adiada pela decisão de contrato do coordenador.

## Alteração

- Migration criada pela CLI: `20261116185619_t12_claim_evolution_dispatches.sql`.
- A RPC `public.claim_evolution_dispatches(p_limit integer DEFAULT 10, p_lease_seconds integer DEFAULT 60) RETURNS SETOF public.evolution_event_dispatches` valida limites `1..10` e lease `1..60`.
- A claim seleciona pending vencido e processing com lease expirada via `FOR UPDATE SKIP LOCKED`, incrementa attempts até 5, gera token/lease novos e não reabre estados terminais.
- Roots vencidas com attempts 5 passam a failed, limpam a lease/token e recebem `attempts_exhausted` somente se ainda não havia erro.
- A função é `SECURITY INVOKER`, fixa `search_path` e concede execução somente a `service_role`.
