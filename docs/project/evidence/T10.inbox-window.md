# T10 Inbox text and expired session window

## Change

Evolution text composition and submission no longer depend on the Meta 24-hour
customer-session window. The thread no longer displays the session countdown,
and the composer no longer shows the expired-session warning or its template
button. A focused submission policy test covers nonempty text with the
capability enabled and no unresolved operation, regardless of session age.

The existing `sessionExpired` guard remains attached to non-text composer
actions. Media, templates, interactive messages, and other non-text paths remain
disabled as before. Read-only roles, the text capability gate, empty-draft
guard, pending-operation gate, reply rejection/preservation, operation status,
and reconciliation behavior remain in place.

## Limits

The 24-hour calculation is retained only to preserve the existing non-text
action guard. This change does not enable media, template, or interactive
capabilities and does not change capability configuration.
