# T12 — entrada local da escolha em botões e listas

Em 17/11/2026, o recebimento Evolution passou a identificar IDs explícitos de resposta a botão ou linha de lista. O evento é gravado sem o envelope bruto e a mensagem entra uma vez na conversa com `interactive_reply_id`. A RPC cria apenas a tarefa do Flow ativo da mesma conta, conversa e contato quando o ID corresponde a uma opção configurada. Ela não cria tarefas de automação ou IA para essa escolha.

A migration `20261117051742_t12_flow_interactive_reply_ingress.sql` foi aplicada só no Supabase local. Testes sintéticos em transação com rollback cobriram botão, lista, replay, ID não configurado, eco, grupo e separação entre contas. Os três testes de código focados somaram 94 casos; TypeScript e `git diff --check` passaram. Nenhuma chamada real à Evolution ou ao WhatsApp foi feita.

Ainda falta o executor usar essa tarefa para enviar o prompt, reconhecer a escolha e avançar o Flow. Não há tarefa interativa real pendente no banco local. A ativação de botões e listas permanece bloqueada.
