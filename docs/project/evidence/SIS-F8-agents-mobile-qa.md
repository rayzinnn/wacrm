# SIS F8 — Agentes de IA em 320 px

Em 17/11/2026, a tela `/agents` foi aberta no portal local com viewport de 320 px. Cabeçalho, estado “Não configurado”, três abas e o início do formulário de configuração permaneceram legíveis. Após rolar pelo formulário, `innerWidth` e `documentElement.scrollWidth` continuaram em 320 px. Não houve rolagem horizontal nem ação bloqueada pelo layout nesta inspeção.

Não inseri chave de API nem salvei configuração. Esta rodada não inclui leitor de tela, navegação completa por teclado ou zoom real de 200%. Não identifiquei mudança de código necessária nessa tela.
