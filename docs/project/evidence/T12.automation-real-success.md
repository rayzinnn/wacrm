# T12 — automação confirmada no teste real

Data: 17/11/2026 (America/Sao_Paulo).

Após o usuário enviar novas mensagens ao WhatsApp pareado, os registros da automação `Cadastro no CRM` mostram três execuções recentes em estado `success`. Cada uma contém exatamente uma ação `create_deal` em estado `done` e um identificador de negócio. A tabela `deals` passou de 1 para 4 registros, e os três novos IDs coincidem com os resultados das ações. Assim, o caminho mensagem recebida → gatilho de palavra-chave → tarefa local → primeira ação → negócio foi observado no localhost. As duas tarefas anteriores à correção continuam com zero ações e não foram alteradas.

Esta prova cobre a automação de palavra-chave com `create_deal`; não cobre os demais gatilhos e ações automáticas.
