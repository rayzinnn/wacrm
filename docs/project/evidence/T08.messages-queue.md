# T08 — durable queue for normalized inbound text

Date: 2026-11-16. Scope: accept only events emitted by the existing normalizer into the durable Evolution event queue. No domain processing, SQL migration, or Evolution webhook configuration was changed here.

## Implementation

- The authenticated webhook now sends all normalized events to `enqueueEvents`. The normalizer emits a message only for the observed inbound plain-text shape; unsupported event variants remain ignored.
- The queue persists an explicit projection of message fields and deduplicates by `(connection_id, event_key)`. It does not persist raw callback payloads or envelope/context secrets.
- The webhook awaits queue persistence before returning 200. A replay returns the queue's duplicate count; persistence failure returns sanitized 503. Authentication errors stop before normalization and enqueue.
