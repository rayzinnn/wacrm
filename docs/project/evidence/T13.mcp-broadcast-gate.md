# T13 — remover broadcast da descoberta MCP

Data: 2026-11-16. Escopo limitado ao pacote MCP, documentação do próprio servidor e evidência. Rotas Next, Evolution, banco, interface do CRM e outros transportes não foram alterados. Nenhuma chamada à API nem envio foi feito.

## Alterações

- A descoberta MCP não registra mais send_broadcast nem get_broadcast; o módulo tools/broadcast.ts foi removido e o leitor de status não é mais registrado.
- A configuração deixou de interpretar WACRM_ENABLE_BROADCASTS e não possui mais enableBroadcasts. Se a variável antiga continuar no ambiente, ela é ignorada e não impede a inicialização, mesmo sem WACRM_ENABLE_WRITES.
- WacrmClient não mantém wrappers para POST/GET /api/v1/broadcasts, que retornam 422.
- README do mcp-server não anuncia ferramentas, opt-in ou confirmação de broadcast.
- Ferramentas read permanecem sempre disponíveis. Com WACRM_ENABLE_WRITES=true, send_message de texto, create_contact e update_contact continuam registrados.
