# Evidência T08.b — caixa durável de eventos Evolution

## Implementação

- `enqueueEvents(connectionId, events)` grava em `evolution_events` pelo `supabaseAdmin()` lazy existente. Entrada vazia retorna `{ inserted: 0, duplicates: 0 }` antes de construir/acessar cliente.
- Cada linha é projetada explicitamente como `connection_id`, `event_key` e `normalized_event: { kind, eventKey, occurredAt }`. Propriedades extras, envelope externo, `apikey` e segredos não são persistidos.
- As chaves do lote são deduplicadas antes do banco, preservando a primeira ocorrência. Uma chamada bulk `upsert` usa `onConflict: 'connection_id,event_key'` e `ignoreDuplicates: true`; `.select('id')` conta apenas linhas inseridas. `duplicates` é o tamanho original do lote menos o total inserido. Conflito com linha persistida não faz update.
- Erro retornado, rejeição ou throw do cliente/query é convertido para `EventQueueError` constante (`event_queue_unavailable`, HTTP 503, `Evolution event queue is unavailable.`), sem causa bruta.

- GREEN após implementação: mesmo comando — 8 testes passaram. Cobertura: lote atômico e opções de conflito, retry persistido sem sobrescrita, chaves repetidas no lote, vazio sem cliente, projeção contra propriedades extras, erro retornado e throws do cliente/query sanitizados.
- `npm run typecheck` — exit 0.
- `./node_modules/.bin/eslint src/lib/whatsapp/evolution/event-queue.ts src/lib/whatsapp/evolution/event-queue.test.ts` — exit 0.
- A [referência JavaScript de upsert do Supabase](https://supabase.com/docs/reference/javascript/upsert) descreve bulk upsert e `.select()` para retornar linhas; o código usa `.select('id')` após upsert para contar inserções. Não rodei a suíte completa nem alterei/testei migrations ou banco neste recorte.

## Limites

Os testes usam client/query doubles; não fizeram gravação no Supabase local. A atomicidade esperada decorre de um único bulk upsert submetido como uma operação. Esta caixa só grava eventos normalizados recebidos; não executa consumidor, ACK de rota, mensagens, mídia ou processamento.
