# T12 — texto de saída em Flow Evolution

Em 17/11/2026, o nó `send_message` passou a usar a reserva e o adapter de texto Evolution. Cada etapa tem um request ID estável; uma tentativa já reservada é reconciliada sem outro POST. Só o aceite confirmado permite gravar `message_sent` e avançar o Flow. Resultado pendente espera, e entrega desconhecida ou rejeitada falha fechada.

Verificações: 17 testes focados do executor, incluindo aceite, replay, pendência, resultado desconhecido e lease ausente; `tsc --noEmit`, ESLint e o build Next passaram. As suites SQL rollback-only de claim de envio e transição Flow passaram no Postgres local. A suíte integral passou: 200 arquivos/2.165 testes.

Nenhum texto automático foi enviado ao WhatsApp nesta verificação. Não existe Flow ativo no banco local neste momento; o teste real de início/fim usou apenas nós sem envio e removeu as fixtures. `collect_input`, interativos, mídia de saída e handoff ainda não foram integrados ao Flow Evolution.
