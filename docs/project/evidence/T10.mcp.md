# Evidência T10.mcp — cliente de texto MCP

Data: 2026-11-16. Escopo: cliente público MCP, ferramenta `send_message`, testes isolados e documentação local.

## Implementação

- `send_message` expõe apenas `to`, `text` e `idempotency_key`. O schema estrito exige chave explícita, não vazia, com até 200 caracteres; template, mídia e reply são rejeitados, sem silenciosamente remover contexto não suportado.
- O handler encaminha `type: "text"` e passa a chave sem alteração ao cliente. `WacrmClient.sendMessage` exige chave no contrato TypeScript e encaminha `Idempotency-Key` para `POST /api/v1/messages`. Não cria, troca ou gera chave.
- Retry é uma chamada explícita do cliente MCP com os mesmos argumentos e a mesma `idempotency_key`; uma chamada do tool resulta em exatamente um POST HTTP. O server-side mantém a reserva T10 para impedir novo POST ao provider em replay.
- Não foi adicionada consulta de status para API key. O endpoint de operação documentado em T10.operations usa sessão de usuário, e não há contrato/rota de consulta autenticada por API key nesta tarefa. O resultado incerto pode ser tentado novamente explicitamente com a mesma chave; nenhuma segunda chamada automática ou rota foi inventada.
- Configuração de opt-in (`WACRM_ENABLE_WRITES`) e escopo `messages:send` permanecem intactos; API v1 autentica, autoriza e valida o tipo textual. A capability visual da Inbox continua desligada neste recorte, embora a rota v1 já aceite texto com chave idempotente. Nenhuma capability foi ativada aqui.

## Verificações

- `npx vitest run --config mcp-server/vitest.config.ts`: 2 arquivos, 3 testes passaram. Fetch e cliente MCP são mockados; os casos verificam um POST, caminho v1, header/chave literal, corpo texto, schema text-only, chave obrigatória e rejeição de template/mídia/reply.
- `npm --prefix mcp-server run typecheck`: passou após declarar `types: ["node"]` no `mcp-server/tsconfig.json`, tornando os globals de runtime Node explícitos sob TypeScript 6.
- Nenhuma chamada real à API ou WhatsApp foi feita. Nenhum commit foi criado.
