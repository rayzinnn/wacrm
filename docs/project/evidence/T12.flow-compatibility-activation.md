# T12 — ativação compatível com Flow Evolution local

Em 17/11/2026, o editor e a API de ativação passaram a mostrar os mesmos erros para ações que o executor Evolution local ainda não executa. O gatilho manual e os nós `send_buttons`, `send_list`, `send_media`, `handoff` e `http_fetch` impedem ativação. Fluxos com palavra-chave ou primeira mensagem e nós `start`, `condition`, `set_tag`, `send_message`, `collect_input` e `end` continuam elegíveis. Rascunhos podem ser salvos, pausados e excluídos.

O bloqueio também é aplicado ao salvar a edição de um fluxo já ativo, para que uma chamada direta à API não coloque nele uma etapa indisponível. As mensagens do editor foram traduzidas em português, inglês, espanhol e coreano. Para botões/listas, a mensagem esclarece que texto simples não oferece a mesma interação; para outras ações, permite manter o fluxo como rascunho.

Verificações: 55 testes focados de validação e rotas; suíte integral com 200 arquivos/2.172 testes; TypeScript, ESLint focado, JSON das quatro traduções, `git diff --check` e build Next passaram. Nenhum envio ao WhatsApp foi feito.

O usuário confirmou que o fluxo testado era palavra-chave seguida de botões ou lista em `http://localhost:3000`. O gatilho foi corrigido no recorte anterior, mas esses nós ainda não estão integrados ao executor. O banco local está sem fluxos cadastrados neste momento; não houve reprodução final do fluxo do usuário. A pesquisa do canal real da instância pareada continua antes de planejar o envio interativo.
