# T06.c1 — reservas e conclusão de envio de texto

Data: 2026-11-16. Migration aplicada exclusivamente à stack Supabase local em `127.0.0.1:54322`.

## Implementação SQL

Migration criada pelo CLI existente com `supabase migration new evolution_send_text_rpcs`: `20261116170118_evolution_send_text_rpcs.sql`. A migration adiciona somente `reserve_evolution_send` e `complete_evolution_send`, além de revogar EXECUTE público/anon/authenticated da função trigger de namespace existente. As RPCs são `SECURITY INVOKER`, usam `search_path = pg_catalog, public, pg_temp`, e EXECUTE é concedido somente a `service_role`.

A reserva deriva a conta da conexão Evolution e confere conversa, contato, perfil do autor e reply-to na mesma conta/conversa. Aceita apenas payload fechado de texto; campos de mídia/template/interativo só aceitam JSON null. A tentativa e a mensagem `sending` são criadas atomicamente sob `UNIQUE(account_id, request_id)`. Replay devolve IDs existentes com `should_send=false`; divergência de hash/conversa falha. Pending acima de 120 s vira `unknown` com `pending_expired`, sem mudar a mensagem `sending` nem permitir novo envio.

A conclusão valida os vínculos attempt/conexão/conta/conversa/mensagem/autor sob lock. Aceite exige ID remoto, persiste attempt e mensagem na mesma transação e não rebaixa `delivered/read`; rejeição só marca `failed` quando a mensagem ainda está `sending`; `unknown` deixa a mensagem sem conclusão presumida. Replays terminais idênticos são no-op; outcomes/IDs conflitantes falham. Erros externos são sanitizados por regex curta para `worker_error`; colunas de erro históricas de `messages` não são preenchidas.

Na mesma migration, o corpo de `track_conversation_message_times()` foi atualizado preservando assinatura, owner `postgres`, `SECURITY DEFINER`, `search_path` e ACL vigentes. O comportamento de resposta legacy continua; Evolution `sending`/`unknown` e rejeições não avançam `last_reply_at`; aceite confirmado avança usando `messages.created_at`; resposta Evolution aceita que vira `failed` recalcula a métrica com aceites Evolution e mensagens legacy não falhas.
